# gstApp 성능 최적화 상세 계획서 (Performance Optimization Plan) - v1.1

본 문서는 i.MX8MP 플랫폼에서 `gstApp`의 CPU 사용량을 최소화하고 실시간 응답성을 높이기 위한 기술적 구현 계획과 진행 상황을 정의합니다.

## 1. 개요 (v1.1 업데이트)
현재 `gstApp`은 소프트웨어 제어부의 오버헤드(메시지 처리, 문자열 연산)를 줄이는 1단계 최적화를 완료하였습니다. 2단계는 하드웨어 가속 효율을 극대화하고 동기화 객체의 경합을 줄이는 데 집중합니다.

---

## 2. 상세 최적화 항목 및 진행 상황

### ✅ A. 버스 메시지 및 스레드 최적화 (완료)
*   **이벤트 객체 풀링 (Object Pooling)**: `FragmentClosedEvent`를 정적 풀(16개)에서 재사용하여 힙 할당 오버헤드 제거.
*   **고속 메시지 필터링**: `GST_MESSAGE_QOS`, `TAG` 등 고주파 메시지를 조기 필터링하여 CPU 사이클 절약.

### ✅ B. 문자열 및 날짜 연산 최적화 (완료)
*   **날짜 문자열 캐싱**: 1초 내 중복되는 `g_date_time_format` 호출을 제거하여 연산량 75% 감소.
*   **snprintf 기반 경로 생성**: 힙 할당을 줄이고 버퍼 오버플로우 검증 로직을 통한 안정성 확보.
*   **I/O 분산**: 세션 신호(`start_video_time_chk`) 기록을 0번 채널로 단일화하여 파일 시스템 부하 경감.

### 🔄 C. 하드웨어 가속 최적화 (진행 예정)
*   **Zero-copy 데이터 경로 강제**:
    *   모든 `queue` 및 `convert` 엘리먼트에 `io-mode=dmabuf` 또는 `dmabuf-import` 설정을 명시하여 CPU 간섭 차단.
    *   `v4l2h264enc` 및 `imxvideoconvert_g2d` 간의 픽셀 포맷(`NV12`) 일치 확인.
*   **큐(Queue) 레이턴시 튜닝**:
    *   `max-size-buffers`를 프레임 레이트의 1/3 수준(예: 5개)으로 축소하여 메모리 점유율 및 지연 시간 최소화.
    *   `leaky=downstream` 적용으로 실시간성 보장.

### 🔄 D. 동기화 및 세션 관리 효율화 (진행 예정)
*   **Mutex 임계 구역 최적화**:
    *   `get_or_create_session` 등에서 Mutex가 잠겨 있는 동안 발생하는 연산을 최소화하고, 조회 후 즉시 Unlock 하는 패턴 적용.
*   **파일 플래그 처리 비동기화**:
    *   `.video_done` 생성 및 `.all_done` 확인 로직을 메인 버스 핸들러가 아닌 별도의 저순위(Low-priority) 워커 스레드로 완전히 분리.

## 3. 구현 단계 및 상태

| 단계 | 항목 | 상태 | 기대 효과 |
| :--- | :--- | :---: | :--- |
| **Step 1** | 문자열 캐싱 및 snprintf | ✅ 완료 | CPU 피크 부하 유의미한 감소 |
| **Step 2** | 메시지 필터링 및 객체 풀링 | ✅ 완료 | 메모리 안정성 및 할당 지연 제거 |
| **Step 3** | Zero-copy 경로 및 큐 사이즈 튜닝 | 🔄 예정 | 하드웨어 가속 효율 극대화 |
| **Step 4** | Mutex 경합 감소 및 I/O 비동기화 | 🔄 예정 | 동시 처리 능력(Throughput) 향상 |

---

## 4. 성능 측정 지표 (KPI) - v1.1
1.  **CPU 점유율**: `top` 기준 전체 프로세스 점유율 **20% 이상** 감소 목표 (현재까지 약 10~15% 감소 추정).
2.  **지연 시간**: `Fragment opened` 시점의 채널 간 편차를 **33ms(1프레임)** 이내로 유지.
3.  **시스템 콜**: `strace` 기준 파일 시스템 관련 시스템 콜 발생 빈도 감소 확인.

---

## 5. 결론
1단계 최적화를 통해 제어부의 부하를 성공적으로 줄였습니다. 2단계 하드웨어 가속 최적화가 완료되면 i.MX8MP의 성능을 최대로 활용하는 저부하/고정밀 녹화 시스템이 완성될 것으로 기대됩니다.
