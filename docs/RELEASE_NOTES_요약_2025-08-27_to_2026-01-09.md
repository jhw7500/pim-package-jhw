## 🚀 주요 신규 기능

### 1. gstApp v1.2 - 캡처 시스템 대폭 개선
- **비동기 캡처**: 워커 쓰레드 기반으로 응답성 향상
- **요청 큐 구조**: 연속적인 캡처 명령을 누락 없이 처리
- **인코더 선택 가능**: JPEG, JPEG Turbo, RAW 형식 지원
- **품질 조절**: 0~100 범위로 캡처 품질 설정 가능
- **카메라 회전 재활성화**: 2024년에 제거되었던 streamApp 카메라 회전 기능 복구

### 2. 스토리지 안정성 강화
- **ext4 마운트 최적화**: 파일시스템 타입별 최적화된 마운트 옵션 적용 (ext4: commit=60, data=writeback 등)
- **동적 파일시스템 감지 및 최적화**: 자동으로 SD 카드 파일시스템 타입 판별 (FAT32/ext4/exfat)
- **읽기 전용 감지**: SD 카드 읽기 전용 상태 자동 감지
  - ⚠️ 자동 복구는 v0.5.5에서 추가 후 v0.5.7에서 제거됨
  - 자동 fsck 복구가 시스템 불안정성 유발하여 수동 도구로 대체
- **새 관리 도구**:
  - `ext4_downgrade.sh` - ext4 다운그레이드
  - `chk_filesystem.sh` - 파일시스템 상태 체크
  - `file_manager.sh` - 파일 관리
- **폴백 메커니즘**: SD 마운트 실패 시 `/dev/shm`으로 자동 폴백

### 3. 시스템 서비스 추가
- `sd-mount.service` - SD 카드 마운트 관리 개선
- `ord-operate.service` - ORD 전용 서비스
- `cam-operate.service` - 카메라 동작 최적화

## 🔧 주요 개선사항

### 성능 최적화
- gstApp 메인 루프 최적화로 CPU 사용량 감소
- ext4 커밋 주기 튜닝으로 쓰기 성능 향상
- 캡처 인덱스 계산 로직 개선

### 로깅 시스템 정비
- 모든 앱 로그 레벨 INFO로 통일
- 불필요한 로그 대폭 감소 (gstApp, streamApp, PIMCAM)
- journald 최적화:
  - RAM 사용량 제한 설정
  - 스냅샷 기능으로 영구 저장
  - crontab으로 전환하여 안정성 향상

### ORD v4.7 업데이트
- **에러 전송 주기 설정**: `err_send_period` 파라미터 추가
- **경로 자동 생성**: 디렉토리 없을 시 자동 생성
- **SD 카드 상태 인식**: 마운트 상태 감지 개선
- **초기화 지연**: 안정적인 시작을 위한 딜레이 추가

### 시스템 안정성
- RTC 빠른 로딩으로 로깅 가용성 향상
- fake-hwclock 추가 (RTC 없는 시스템 대응)
- 기본 타임존 KST 설정
- fsck 잔여 파일 자동 정리
